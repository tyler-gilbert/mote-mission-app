## Ops Role

Your job is to operate the robot.

Startup Tasks:

- Upgrade the debug probe firmware to the latest version
- Connect the robot to the Wifi.
- Assign the appropriate tail number to the robot using the USB serial configuration
- Physically mark the robot with the assigned tail number
- Set up a practice arena. Consult with Ops on the specifications.

Training Tasks:

- Operate the mote mission software
- Use the "Gear" Icon to load a route on the robot.
- Execute a test run by clicking the "Robot" icon.
- Collect Telemetry with the "Record" button.
  - Fast Telemetry is all telemetry at the native rate
  - Slow Telemetry has no LiDAR data and decimated IMU data. GNC/Status are the same
- Ensure batteries are charged.
- Flash test deployment firmware.

Operational Tasks:

- Deploy mission ready software.
- Execute the mission.
